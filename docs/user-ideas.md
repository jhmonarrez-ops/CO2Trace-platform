# User ideas — CO2Trace

Features people in each role would want. Size is a rough build estimate. Ranked within each group; **shipped** items are the top two page-only `[minor]` picks for 2026-11-19 (P-20261117-4).

## SME owner
1. **Getting-started checklist with progress** `[minor]` · **shipped 2026-11-19** — First visit feels clear: five public-safe steps (how → example → evidence → report → account) with a progress bar; never unlocks own-data edits on the public site.
2. **Monthly data-entry reminder (.ics)** `[minor]` · **shipped 2026-11-19** — Download a calendar file with one reminder per month of the reporting year so bills and invoices get entered on time.
3. **Print-friendly one-page summary** `[minor]` — One A4 sheet (total, scopes, top lines, evidence %) for a board or bank meeting without the full ISO report.
4. **Guided first-inventory wizard** `[major]` — Step through company → fuels → electricity → materials with defaults, then land on the ledger; needs new flow and saved state.

## Sustainability / EHS manager
5. **Base-year vs current badge on KPIs** `[minor]` — Show % change vs base year on the total tile so progress is visible without opening the base-year card. Done 2026-11-19.
6. **Board-pack uncertainty blurb** `[minor]` — One-paragraph plain-language note under the uncertainty card for copying into a board deck.
7. **Supplier chase list from Scope 3 hotspots** `[major]` — Turn largest Scope 3 lines into a chaseable supplier list with mailto drafts; touches workflow and possibly accounts.

## Consultant (multi-client)
8. **Multi-client workspace switcher** `[major]` — Switch between several client ledgers under one account; needs cloud and data-model work. See P-20261119-1.
9. **Side-by-side client comparison** `[major]` — Intensity and scope mix across clients for a practice dashboard; depends on multi-client.
10. **Consultant-branded report cover** `[minor]` — Optional practice name/logo on the print report cover (local upload, no server).

## Supplier (answering a customer request)
11. **One-click customer-request reply pack** `[minor]` — From an open request, download the sheet + CSV + a short cover note in one zip (browser-only).
12. **Portal-ready CDP Supply Chain CSV** `[minor]` — Extra CSV columns mapped to common CDP SC fields from the existing allocation.

## Auditor / verifier
13. **Evidence completeness trail export** `[major]` — Chronological pack of every attach / verify / period check for an engagement file. See P-20261119-2.
14. **Line-level change log since last review** `[major]` — Diff of quantities, factors and evidence since a review stamp; needs history storage.
15. **Materiality filter on Checks** `[minor]` — Hide checks under the materiality % so the card matches what a limited-assurance review would chase first.
