# CO2Trace (repo: lca-carbon-ledger) — notes for Claude

- Single static page: `index.html` (inline CSS + JS, no build). Typography and motion follow abatable.com (2026-10-13): one family, Hanken Grotesk from Google Fonts (the free match for abatable's licensed PP Mori; to switch, license PP Mori, self-host it and put it first in the `--f-*` tokens), headings weight 500 with -.03em tracking, card titles 600, small uppercase labels with .06–.08em tracking, sentence-case buttons. The hero tree canvas uses the system monospace font. Smooth scrolling is Lenis 1.3.26 from jsDelivr (pinned, SRI) as `window.lenis`; use `goTo(el, 'center'?)` for in-page jumps, and give any new scrollable box `data-lenis-prevent`. Look: one brand blue #072AC8 (`--brand`: hero, top bar, titles `--title`, kickers `--kick`, Scope 1; `--hero-accent` #AFC0FF for accents on the blue band). Menu bar hovers white (`--menu-hover`), dashboard buttons hover blue (`--go`). Light page #EEF0EB with white 18px-radius cards. Scope colours are a blue scale; status green (`--ok`) is semantic only. The logo stays white.
- Data model (v: 2): `state = { v, company, year, fuName, fuQty, boundary, isExample, region ('us'|'mx'), method ('AR6'|'AR5'|'AR4'), goal{reason, app, audience, comparative, commissioner, practitioner, reportDate, refFlow, allocation, cutoff, exclusions, assumptions, review ('none'|'internal'|'external'|'panel'), reviewer, assurance ('none'|'limited'|'reasonable'), materiality (% string, default '5'), rfc, scian, site, usStates, ca, rev1b}, rows[] }`; each row `{ id, stage, key, supplier, note, qty, unit, ef (kg CO2e/unit, used only when efEdit or key==='custom'), efEdit, scope, m0, m1 (activity months 0–11, inclusive; emissions spread evenly for the Gantt), evidence: { doc, ref, period, verified, files[{fid,name,size,type,added}] } }`. Evidence file blobs live in IndexedDB db `lca-evidence`, store `files`, keyed by fid. Chart view choices (catView radial|treemap, catScope, ganttScope) live in localStorage `lca-ui-v1`.
- `STAGES`, `FACTORS`, `CATS` (emission categories = factor kind) and `DOCS` (evidence document types) are defined at the top of the script. Defaults: `defaultScope()`, `defaultDoc()`, `stageDefault()`.
- Factors store kg of each gas per unit, either `gas` (all countries) or `us`/`mx` (per country), plus `src`/`srcUs`/`srcMx`. `'CO2e'` is a pre-characterised pseudo-gas (LCI datasets, FESEN, edited factors). `GWP[method]` characterises; `emis(r)`, `gasT(r)`, `libEf(key)` do the math. eGRID2023 subregions are appended to `FACTORS` with `only: 'us'`. `V1_EF` lets v1 ledgers upgrade (a factor equal to its v1 library value becomes a library line).
- Country rules: México = RENE (AR5 for threshold and COA export, FESEN, certificates not recognised); US = GHG Protocol (Scope 2 location- and market-based via `s2Location`/`s2Market`, total uses market-based; HCFC-22 outside the scopes via `outside()`). Dashboard adds `complianceCard`, `checksCard`, `inventoryCard`; header has the Project setup panel (`renderSetup`).
- Persisted in localStorage key `lca-ledger-v1`.
- Published copy (claude.ai artifact): https://claude.ai/artifact/84bMVNrhpBWEaeDiyyib1K
- Theme tokens on `:root` with dark-mode overrides; keep colors as tokens.
- GHG Protocol methodology, tool catalogue, GWPs, reporting requirements and the current gap list: `docs/ghg-protocol-tools.md`. Check calculation changes against it.

- Hosting: GitHub Pages from `main` (repo public since 2026-10-07), custom domain co2trace.io via `CNAME`; DNS at GoDaddy. Pushing to main deploys the live site.
- Mexican RENE rules (AR5 GWPs, FESEN grid factor, Mexican fuel factors, COA format): `docs/mexico-rene.md`. SimaPro modelling concepts and how CO2Trace maps onto them: `docs/simapro-model.md`. Planned database (libraries, per-gas process vectors, auto-matching) and UX flow: `docs/database-and-ux.md`.
- Databases (+ From database, `#dbDlg`): factor libraries in `data/libraries/*.json` (+ `index.json`), built from the publishers' downloads by `tools/libraries/build.py` (sources, licences and checks in `tools/libraries/README.md`): EPA supply chain v1.3, EXIOBASE 3.8.2, USLCI FY25 Q2 + US electricity baseline, AGRIBALYSE 3.2, WEEE LCI. The page fetches them lazily (works on co2trace.io, not in the artifact or from file://). A picked factor is copied into `state.lib[key]` (`{key, g, name, unit, kind, gas, lib, src, cite}`) and registered into `FACTORS`/`F` by `registerFactor()` at load, so rows keep working offline; `save()` prunes unused entries. Keys look like `uslci:xxxxxxxx`, `epa:331110`, `agb:6250`, `weee:…`, `exio:MX:12`. `MORE_GWP` adds the other Kyoto gases (SF6, NF3, PFCs, HFC-23/152a/236fa) to `GWP`; CSV/COA exports add a column per extra gas only when a line has it (`setGases()`). HCFC-22 traces are dropped from database factors. Never use EXIOBASE ≥3.9 (non-commercial). WEEE data may only be redistributed free of charge; BAFU needs a Nexus login and must stay in the background of a paid tool.
- Language follows the country: México = Spanish (es-MX), US = English. Static text carries `data-es` / `data-es-placeholder|title|aria-label`; `applyLang()` (called from `renderMeta`) swaps them and switches `CATS`, `METHODS`, `DOCS`, `MONTHS`, stage, factor and region names. Rendered text uses `L(en, es)`, `SC(s)` (Scope/Alcance) and `SA(s)` (S1/A1). México-only text (RENE card and checks, COA) is Spanish only; US-only text is English only. `example(region, id)` writes the Mexican (Spanish) or American (English) company for that example id, and switching region rewrites an untouched example.
- Top bar (`#topbar`, modelled on sincro.es): fixed, with a dark `.bar-space` spacer under it; gets `.compact` once scrolled. Menu groups are `.grp > .tile + .drop`: with a mouse (`(hover: hover) and (min-width: 921px)`) hovering opens a group and the label slides from the bottom of the tile to the top, as on sincro.es; click also toggles; blurred `#scrim`, Esc closes; below 920px the Menu button opens them as a full-height sheet. Drop links scroll to ids, including dashboard cards (`#c-comp`, `#c-checks`, `#c-scope`, `#c-gantt`, `#c-sup`, `#c-hot`), so keep those ids when editing the card templates. `--bar-h`/`--bar-full` hold the bar height for the sticky dashboard and `scroll-padding-top`.
- Hero: one dark tone (`--forest` #252422, set as `--hero` inside `.hero` only; the top bar, Total KPI and Method panel stay brand blue). Text, Create account / Sign in buttons (`[data-acct]`, open `#acctDlg`: a Create account / Sign in box with company, name, email and password. There is no account server yet, so submitting only checks the fields, clears the password, sends nothing and says so; "Continue without an account" goes straight on. Wire it to Cognito when the backend is deployed) and the tree (`#treePanel`, no box). The tree is a canvas of glyphs on an 8px grid (second `<script>` at the end of the page), built from a seeded branching tree with roots: growth starts at the root tips, climbs the trunk and branches and ends with the canopy, each glyph scrambling as the front reaches it (after the animal on twks.ch); then it sways at ~30 fps, flickers, and the pointer pushes glyphs aside; a click grows a new seed. Respects reduced motion and pauses off screen. Headless Chrome on this Mac never fires requestAnimationFrame, so test it with a copy that swaps rAF for setTimeout and drops the Google Fonts link.
- Phones (`@media (max-width: 640px)`, "Phones" block near the end of the CSS): ledger rows become labelled cards (`table.ledger`, each `td` carries `data-l` for its label; keep it when adding columns), the hero paragraph clamps to four lines with `#ledeMore`, setup and KPIs go two-up, inputs are 16px so iOS doesn't zoom. `.on-hover` / `.on-touch` spans swap "hover" wording for "tap" on touch screens.
- About us (`#about`, after Method, menu group 04): same dark tone as the hero, with Vision / Mission / Purpose cards (`#vision`, `#mission`, `#purpose`) and the socials row (`#socials`). LinkedIn, Instagram and X links still point at the platform home pages until the real profile URLs are known; GitHub points at the repo.
- Help chat (`#helpFab` + `#helpChat`, `helpChat()` near the end of the main script): no backend and no AI model; it matches the question against `TOPICS` (English and Spanish keywords, 5-letter stem match) and answers in the page language. `live.*` answers (total, hotspots, evidence, RENE) read `totals()` so they match the dashboard; answers can carry buttons that scroll to section ids. Add a topic when you add a feature. To make it a real AI assistant later, route questions through the backend (never put an API key in the page).
- ISO checks (2026-10-13): the Goal and scope panel is grouped by `.pg-head` rows (Goal of the study / Scope / Review and verification / country block). `checks()` adds ISO 14044 goal-completeness, panel review for public comparisons, stage completeness, negative-line (no netting), evidence-period-vs-reporting-year and materiality checks; goal keys that feed the dashboard are listed in `GOAL_CHECKED`. `csv()` writes the goal-and-scope block (ISO 14044, 5.2 order) above the line table. Cite ISO only by number and clause; never paste standard text into the page or repo.
- Page order inside `.wrap`: `#lca` (What is an LCA), `#how` (How to use CO2Trace), `#examples` (example gallery, "Start here"), `#projectSetup` (Project setup card, "Your own data"), `#setup` (Goal and scope), `#exampleBanner`, KPIs, ledger + dashboard, Method, About, `#demo` (full video).
- Examples (2026-10-13): `EXAMPLES` holds four fictional companies per country (`{ emp, size, ind[en, es], build(T, X, P), us(X, P) }`): `build` writes the Mexican company in Spanish, `us` an American one in English (same industry, size and activity lines, US cities, eGRID subregion grid, US suppliers, `usStates`/`ca`/`rev1b` instead of RFC/SCIAN). US versions: Blue Mesa Sparkling Water, San Antonio TX (ERCT, 24 GWh so the scopes stay in thirds: 8,206 / 8,064 / 8,797 t, total 25,067); Ridgeline Stamping, Warren MI (RFCM); Rio Valley Citrus, Mission TX (ERCT); Sun City Print Shop, El Paso TX (AZNM). Mexican versions, all cradle-to-gate: `agua` Agua Mineral Cerro Alto (sparkling-water bottler, Monterrey, large; per case of 24 glass bottles; tuned so Scopes 1/2/3 are about a third each: MX/AR5 8,026 / 7,992 / 8,445 t, total 24,463, 3.3 kg/case; US/AR6 8,206 / 7,992 / 8,797, total 24,994), `autopartes` Autopartes Cumbres (auto parts, Santa Catarina, large; 8,125 t MX), `citricos` Cítricos Valle de Montemorelos (citrus grower and packer, medium; one custom urea factor), `imprenta` Imprenta Barrio Antiguo (print shop, small). `example(region, id)` builds one (`state.example` keeps the id); `?demo` loads the first, `?demo=<id>` a given one. New visitors and untouched examples open an example, never a blank ledger. The `#examples` gallery (`renderExamples()`, totals per card via `exSummary()`, which swaps `state` briefly) loads one with `loadExample(id)`; the last card, Your own data, first opens the account box (`window.openAccount(mode, onDone)`, see Hero), then `openOwn(company)` restores the visitor's own ledger, which is kept in localStorage `lca-ledger-own` whenever an example replaces it (blank if there is none). View mode: while an untouched example is loaded, `renderView()` sets `html.viewing` (Project setup hidden, dashboard full width, ledger folded) and fills `#exampleBanner` with the company line and the `#ledgerToggle` button (`html.ledger-open`); any edit calls `touched()`, which ends view mode. If the first example changes, update the `#how` mock (English text = US company, `data-es` = Mexican one; row values, `data-en` / `data-es-n` counts, percentages, donut dash values) and re-record the video (English uses the US company).
- How to use (`#how`): a sticky mock app window (`#howMock`, `data-step` 1–5: setup, ledger, evidence, dashboard, checks/export) driven by an IntersectionObserver on `.how-steps li` (the step crossing the middle of the screen), with progress dots (`[data-go-step]`) and a count-up of the KPI numbers on step 4. Never put HTML elements such as `<span>` inside inline SVG: the parser drops out of the SVG; put `data-es` on the SVG `<text>` itself.
- Full video (`#demo`): `media/co2trace-demo-{en,es}.mp4` (H.264 1440×900 with AAC audio) with `.jpg` posters; the source follows the page language. Recorded by `tools/demo-video/record.js` (Playwright + ffmpeg, see its README); the music and sound effects are synthesised by `tools/demo-video/audio.js` (no samples, nothing to license) at cues the recorder logs.
- What is an LCA (`#lca`, menu group 03): definition (ISO 14040/14044/14067), the life-cycle loop SVG (`#lcaLoop`: five stage nodes, cradle-to-gate arc, dashed recycling segment, a dot on `animateMotion#lcaDot` that loops every 10 s with each node's `.halo` pulsing as it passes, `--i` = node index × 2 s), the four phases list linking to the matching app sections, and four "Why it matters" cards. Scroll reveal: elements with `.rv` fade up once (`.in`) via an IntersectionObserver in the last `<script>`; the script adds `html.rv-on` only when motion is allowed, so without it everything is static and visible. `.rv` is also on Project setup, Method and the About us kicker and pillars; don't put it on dashboard content that re-renders. Section `h2`s carry `.rv-h` (mask wipe; the observer watches the parent because a fully clipped element never intersects). `.scrub` paragraphs (LCA definition, About lede) are split into `.w` word spans that light up with scroll progress; a MutationObserver re-splits them after `applyLang()` rewrites the text.
